Privacy Policy

AlienXFile — temporary file and text sharing. Last updated 4 October 2026.

Overview

AlienXFile is a temporary file and text sharing service. It has no accounts, no sign-up, and no login. You share content and receive a short code; anyone who has the code or link can open the share until it expires. This page explains what is stored, who processes it, and how long it is kept.

What we store

  • Share records in our database (PostgreSQL, operated by Neon): the share code (a random short code or one you chose), the type (file, folder or text), the file name, the size, the chosen expiry time, and where the file bytes are stored. Folder shares also store the list of file names, sizes and storage links.
  • Text shares: the text itself is stored server-side, unless you password-protect it (see below). Text is limited to {{ "{:,}".format(max_text_length) }} characters.
  • File bytes: files are not stored in the database. They are uploaded to the storage providers listed under “Service providers”. Website files are up to 1 GB per file.
  • Password-protected shares: only encrypted content plus a random salt and IV — never your password.

Password protection

If you set a password on the website, your browser encrypts the content before it leaves your device using AES-GCM (256-bit) with a key derived from your password by PBKDF2 (SHA-256, 100,000 iterations). The server receives only the encrypted content, the salt and the IV. The password itself is never sent to the server. We cannot recover a lost password, and we never see the plaintext of a password-protected share. Passwords are not accepted through the ChatGPT integration.

Expiry and deletion

  • Every share expires after the lifetime chosen at upload: 1 hour, 12 hours, 1 day or 3 days on the website, and up to 7 days through the ChatGPT integration.
  • Expired shares can no longer be opened; this happens as soon as the expiry time passes.
  • Database records and stored files are removed during cleanup, which runs as the service processes activity. Third-party temporary storage removes its files when their lifetime ends.
  • Shares are temporary — not a backup. Keep your own copy of anything important.

IP addresses and rate limiting

We use IP addresses only to limit abuse:

  • Short request-rate windows per IP (by default 30 uploads and 30 lookups per 10 minutes on the website, with separate limits for the ChatGPT integration). These rows keep an IP address only for about 10 minutes.
  • Daily upload-volume budgets for the ChatGPT integration (by default 50 MiB per IP per day and 300 MiB in total per day). These counters keep an IP address for up to 24 hours.

IP addresses are not used for analytics, advertising or profiling, and are not shared with the storage providers.

Logs

We keep operational server logs on our host so the service can be monitored and debugged. They contain event messages such as errors, storage-provider failures, rate-limit events and blocked download hosts (host name only). We do not log share contents, passwords, request bodies, or signed storage URLs. Logs are retained by our hosting provider according to its platform settings.

Service providers that process data

  • Render — application hosting (Singapore region) and log delivery; receives all requests to this site.
  • Neon — PostgreSQL database; receives share records.
  • Vercel Blob — private file storage; receives file bytes for normal uploads.
  • Litterbox (catbox.moe) — third-party temporary file storage; receives file bytes for large or legacy uploads, and deletes them when their lifetime ends.
  • Our upload proxy (alienxfile-proxy.fly.dev, Fly.io) — routes some Litterbox uploads; sees the file bytes it forwards.
  • OpenAI (ChatGPT) — when you use the ChatGPT integration, OpenAI sends tool requests to this service, and this service downloads files you attached in ChatGPT from OpenAI-provided temporary addresses (oaiusercontent.com / openai.com).
  • Google Fonts — pages request fonts from Google Fonts (fonts.googleapis.com / fonts.gstatic.com), which receives your IP address.

We do not sell data, and there are no ads and no analytics on this site. We do not set cookies. Dark-mode preference and upload history are stored only in your own browser (localStorage).

Your choices

  • Pick the shortest lifetime that works for your share.
  • Use password protection for anything sensitive — the server never sees the password or plaintext.
  • Remember that a code is not encryption: anyone with the code can read a non-password-protected share until it expires, so avoid sharing sensitive content you would not want a link holder to see.
  • Questions, or a request to remove a share you know the code for: use the Support page.
